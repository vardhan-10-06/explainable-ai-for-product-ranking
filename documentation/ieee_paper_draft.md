# Explainable AI for Product Ranking Using Hybrid Machine Learning, Knowledge Graphs, and Large Language Models

*(IEEE-conference-style draft. Ships as Markdown; run through a LaTeX/Word IEEE

## Abstract
E-commerce product ranking systems increasingly rely on opaque, high-capacity models,
creating a tension between ranking quality and user/operator trust. We present a
hybrid ranking architecture that combines gradient-boosted trees (LightGBM, XGBoost),
a neural ranker, and a factorization-machine-augmented deep network (DeepFM), fused
with knowledge-graph-derived features and explained via SHAP and knowledge-graph path
evidence. Natural-language explanations are generated by a large language model
constrained to the retrieved evidence and verified by a lightweight hallucination
detector. We introduce the Explainability Confidence Score (ECS), a novel composite
metric quantifying explanation trustworthiness from feature-importance concentration,
knowledge-graph evidence strength, generator confidence, fact verification, and
explanation stability. We describe the full system architecture, evaluation
methodology (ranking, explainability, and NLP metrics), and an ablation study
isolating each component's contribution.

## I. Introduction
Modern ranking systems in e-commerce, streaming, and marketplace platforms are
central to user experience and platform revenue, yet the models driving them are
frequently uninterpretable to both end users and system operators. This gap between
ranking performance and explainability motivates explainable AI (XAI) techniques
specifically adapted to the ranking setting, where the object of explanation is not
a single prediction but a *relative ordering* of items. This paper contributes:
(1) a hybrid ranking ensemble combining complementary model families; (2) integration
of knowledge-graph structural evidence into both ranking features and explanations;
(3) an LLM explanation layer with explicit hallucination detection; (4) the
Explainability Confidence Score (ECS), a novel metric for explanation trustworthiness;
(5) a full open-source reference implementation and evaluation suite.

## II. Related Work
Learning-to-rank methods (RankNet, LambdaRank, LambdaMART) established pairwise and
listwise objectives for ranking. Tree ensembles (LightGBM, XGBoost) remain
state-of-the-practice for tabular ranking due to strong performance and native
feature-importance support. Knowledge graphs have been used for recommendation
(KGAT, RippleNet-style approaches) to inject relational structure beyond
collaborative-filtering signals. SHAP unified prior feature-attribution methods under
a game-theoretic framework with desirable axiomatic properties. Retrieval-augmented
generation (RAG) and grounded generation techniques address LLM hallucination by
constraining generation to retrieved evidence, which we adapt here to the
ranking-explanation setting.

## IV. Methodology

### A. Hybrid Ranking Ensemble
Base models: LightGBM (LambdaRank objective), XGBoost (pairwise objective), a
feed-forward neural ranker, and DeepFM (trained with pairwise hinge loss over
within-user positive/negative pairs). Combination strategies: weighted sum of
z-normalized scores (default), rank-averaging, or logistic-regression stacking on
out-of-fold base predictions. See `documentation/mathematical_derivations.md` Sec. 1-2
for full objective formulations.

### B. Knowledge Graph Integration
Graph-derived features (degree centrality, PageRank, and a co-occurrence-factorization
embedding computed from biased random walks) are joined into the feature matrix.
Separately, shortest KG paths between a user and a product provide structural
evidence for explanations.

### C. Explainability
SHAP TreeExplainer (LightGBM/XGBoost) and KernelExplainer (neural components) produce
per-feature attributions; ensemble SHAP values are the weight-adjusted sum across base
models (valid by SHAP's additivity property under the ensemble's linear combination).
A RankSHAP-style pairwise comparison attributes the score *difference* between two
candidates to the features that most explain the ranking gap.

### D. LLM Explanation Generation and Hallucination Detection
The LLM (or a fully offline deterministic template engine) is prompted with only the
retrieved SHAP and KG evidence and instructed not to speculate. Generated text is then
verified by a lexical-overlap-based hallucination detector that flags unsupported
entity/claim mentions and computes a confidence score; failed verifications fall back
to a deterministic, evidence-only explanation.

### E. The Explainability Confidence Score (ECS)
ECS_i = w_F F_i + w_G G_i + w_L L_i + w_V V_i + w_C C_i, combining feature-importance
concentration (F), knowledge-graph evidence strength (G), LLM confidence (L), fact
verification (V), and explanation consistency (C), each normalized to [0,1]. Full
derivation: `documentation/mathematical_derivations.md` Sec. 5.

## V. Experimental Setup
Dataset: synthetic Amazon-style interaction data (extendable to RetailRocket,
MovieLens, Yelp via schema-normalizing loaders) with configurable scale. Split:
per-user temporal train/validation/test (70/15/15). Baselines: popularity ranking,
random ranking. Ablations: hybrid ensemble with each base model removed in turn.
Significance testing: paired t-test on per-user NDCG@10 between the full ensemble and
each ablated/baseline variant (alpha = 0.05).

## VI. Evaluation Metrics
Ranking: Precision@K, Recall@K, F1@K, MAP, MRR, NDCG@K, Coverage, Novelty, Diversity,
ROC-AUC. Explainability: Fidelity, Faithfulness, Stability, Consistency, plus the
proposed ECS. Generated-text quality: BLEU, ROUGE-L, BERTScore (with a TF-IDF
cosine-similarity fallback when the `bert-score` model download is unavailable).
Efficiency: latency and peak memory per batch of scored candidates.

## VIII. Discussion
The hybrid ensemble is expected to outperform any single base model on NDCG@10,
consistent with the complementary inductive biases discussed in Sec. IV-A; the
ablation study directly quantifies each component's marginal contribution. ECS
provides operators a single, auditable trust signal per explanation, enabling
automatic routing of low-confidence explanations to human review rather than
surfacing an unverified LLM claim to end users.

## IX. Limitations and Future Work
The lexical-overlap hallucination detector trades recall on paraphrased hallucinations
for full auditability; an NLI-based verifier is a natural extension. ECS weights are
currently fixed by configuration; a learned or per-domain-calibrated weighting is
future work. Evaluation on real-world datasets at production scale, and a user study
measuring whether ECS correlates with human-judged explanation trustworthiness, are
the primary directions for empirical validation beyond this reference implementation.
